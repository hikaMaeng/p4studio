## 현재 저장 상태와 남은 수용

- [읽기 전용 HTTP snapshot](../../../target/lifecycle-recheck-live-models.json)의 MiMo `09b02f0b-b28b-491c-bdd7-d3264698a217`는 `unloaded`, updatedAt=`2026-10-06T06:04:54.459Z`. 직전 보고의 failed 상태를 현재 상태로 반복하지 않는다.
- stage0/1의 load succeeded 및 unload succeeded/absent는 남아 있다. stage2는 load failed/absent이고 `stage server exited while starting: exit code: 5`가 보존됐다. stage3은 loadOutcome/lifecycle 없이 absent다. 전체 unloaded 표시가 모든 stage의 정상 UNLOAD 또는 정상100건 추론의 증거가 되지는 않는다.
- TUF/복구 계획은 [agent-recovery-plan.md](../../../docs/agent-recovery-plan.md)의 미구현 수용 조건을 유지한다. 이번 재검사에서 강제 회수 UI나 정상 cancel/drain/RELEASE 완료를 확인하지 않았다.
- 실제100건 부하 정상 출력→terminal/RELEASE→stage별 정상 UNLOAD→native 회수 수용은 미실행이다. 기본 회귀 통과만으로 완료 판정하지 않는다.
